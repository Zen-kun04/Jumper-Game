# Jumper Game
This is the first game I developed, and I chose to do it under Unreal Engine.

About 80% of the project was made with no AI assistance (knowledge I got from tutorials and practice), and 20% with AI assistance (just asking how to do/fix some details)

## How to install the game
1. Go to the [releases](https://github.com/Zen-kun04/Jumper-Game/releases) section
2. Download the **Jumper_Installer.exe**
3. Execute the installer
